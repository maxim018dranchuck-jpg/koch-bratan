# Liquid Keyboard

Клавиатура для Android со стеклянными клавишами и размытием фона за ней.
Раскладка как на Samsung: ряд цифр, ЙЦУКЕН / QWERTY, снизу `!#1`, глобус, буфер, пробел, точка, Enter.

## Как получить APK без компьютера (через GitHub)

1. Создай репозиторий на github.com (кнопка New), назови как угодно.
2. Загрузи в него все файлы проекта с сохранением папок (Add file → Upload files), в корне должны лежать `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
3. Открой вкладку Actions → Build APK → Run workflow. Сборка идёт около 3–5 минут.
4. Когда сборка зелёная, открой её и скачай артефакт `LiquidKeyboard-apk` (внутри `app-debug.apk`).
5. Установи APK на телефон (разреши установку из этого источника).

## Как включить

1. Открой приложение Liquid Keyboard.
2. Кнопка «1» включает клавиатуру в системных настройках, кнопка «2» выбирает её для ввода.
3. Нажми на поле проверки и двигай ползунки: изменения видны сразу.

## Как работает размытие

Окно клавиатуры делается прозрачным, а размытие того, что за ним, делает сама система (Android 12+, `setBackgroundBlurRadius`).
Если размытие выключено системой (например, в режиме экономии), подложка автоматически становится плотнее.

## Что есть

- пресеты Liquid Light, Liquid Dark, Clear Glass, Frosted, Aurora;
- ползунки: размытие, плотность подложки и клавиш, кромка, блик, «набухание» при нажатии, оттенок и насыщенность, скругление, зазор, высота, размер букв;
- светлая / тёмная / авто тема, русский и английский, ряд цифр, вибро, буква над клавишей;
- глобус переключает русский и английский: клавиши «выпрыгивают» волной, над пробелом на секунду появляется название языка; если включён один язык, глобус открывает выбор клавиатуры;
- анимации нажатия: клавиша на пружине с отскоком, всплеск света от пальца, соседние клавиши слегка расходятся; всё настраивается ползунками и тремя пресетами (Мягкие, Жидкие, Желе);
- долгое нажатие: ё, ъ, цифры, знаки препинания; долгое нажатие на пробел или глобус открывает выбор клавиатуры;
- своя картинка под клавишами.
